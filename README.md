# HSX WISP Gauges

Current Description of old code: 

Model Comparison Pipeline (MAIN_EVAL_HSX.py): Orchestrates evaluations between Model 1 (HSX/mgrid) and Model 2 (HSX/hill_8_config). It calls Mgrid_Config_import.py and Hill_8_Config_import.py via subprocesses to retrieve the magnetic field vector at each port's WISP probe tip and calculates their angular separation in degrees.

Interactive Probe & Port Analyzer (HSX_probe_field_2.py): Loads the HSX STL geometry mesh (HSX_ASSEMBLY_RECONSTRUCTED.STL) and wall surface grid. Uses PyVista surface normal calculations and flood-fill algorithm (5° tolerance) to isolate flat port faces, determine port centroids, invert normal vectors inward into the vessel, and evaluate $\vec{B}$ at the probe tip (5 cm extension).

Model Configuration Drivers (Mgrid_Config_import.py & Hill_8_Config_import.py): Contain the central port_dict mapping quadrant port locations (A12, A23, AP12, B12, etc., down to sub-positions like TT, MT, MM, MB, BB, IN). They execute single-port evaluations and return stringified $\vec{B}$-field vectors for comparison scripts.

Field Line Tracing & Distance Mapping (HSX_FieldLines.py): Converts Cartesian coordinates $(x, y, z)$ to cylindrical $(r, z, \phi)$, traces magnetic field lines using Flare's Fieldline.trace(), plots 3D field lines alongside port centroids, and calculates the minimum Euclidean distance between traced field lines and port positions.

Divertor Strike Line Analysis (StrikeLine_Calculator.py): Prototypes tracing field lines upstream from divertor strike locations to wall intersection points using toroidal and poloidal angles relative to the magnetic axis.

This file details modifications and plans to update and extend the Wisp code generated by Maxwell Loughan in the Summer of 2026.
